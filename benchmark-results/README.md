# Benchmark results

This directory stores reproducible runs of the
[official mumax³ benchmark](https://github.com/mumax/3/blob/master/bench/bench.mx3)
and comparisons with the CUDA GPU chart published on the
[mumax³ website](https://mumax.github.io/).

- [`apple-m4-macbook-air-20260731/`](apple-m4-macbook-air-20260731/):
  Apple M4 MacBook Air, 32 GB unified memory, Metal backend, 5-run median
  **66.02 M cells/s** at 4,194,304 cells.
