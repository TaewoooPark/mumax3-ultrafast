## Reproduce the run

```bash
make
python3 examples-and-results/run_official_examples.py \
  --binary "$(go env GOPATH)/bin/mumax3" \
  --results-dir examples-and-results/runs/<run-name> \
  --timeout 1800
```

The runner preserves the official HTML and extracted inputs, checks process
exit codes, timeouts, expected OVF/table counts, empty files, and table NaN/Inf
values, then writes `summary.json`.
